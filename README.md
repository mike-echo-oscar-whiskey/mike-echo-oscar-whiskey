### NAME

**kris** — backend engineer in Amsterdam. C# and .NET, backend architecture, and generative AI put to real work.

### DESCRIPTION

I build backends: APIs with clean boundaries, and more and more LLM integration, agents, retrieval and
document processing. I like systems that are simple enough to reason about and honest enough to say
when they are broken.

### OPTIONS

```text
--test-first      A failing test first, then the code that makes it pass.

--fail-loudly     No magic fallbacks. When something is wrong, it fails
                  where you can see it, and says what is wrong.

--dont-know-yet   An honest "I don't know yet" beats a confident guess.
                  Measure first, then say it.

--no-new-debt     Whatever a change made worse, that change fixes.
                  Later is not a plan.

--agent-first     "IDEs are to software development what manual transmission
                  is to driving. Powerful, precise, and once essential, but
                  increasingly replaced by systems that operate at a higher
                  level of intent."
```

it, and send the fix upstream.

Away from the keyboard, I practise handstands and yoga, and I love hiking in the mountains with my
girlfriend.
